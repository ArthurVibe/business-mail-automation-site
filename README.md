# Business Mail Automation

Интерактивное коммерческое предложение, перенесённое из утверждённого HTML-прототипа v4.8. Дизайн, тексты, изображения, демонстрационные тарифы и формулы сохранены. Все основные разделы доступны непрерывной вертикальной прокруткой.

AI-консультанты **демонстрационные**: ответы и извлечение параметров работают локально по правилам. Почта, языковые модели, Make.com и другие внешние API не подключены. Ввод не отправляется на сервер, состояние живёт до перезагрузки страницы. Экономический эффект — оценка стоимости высвобождаемого времени, а не гарантия сокращения расходов.

## Стек и требования

- Node.js 22.12+ в ветке 22 LTS либо Node.js 24+; проверено с Node.js 24.19.0 и npm 11.9.0.
- Vite 7, HTML, CSS и Vanilla JavaScript ES modules.
- Prettier 3; `node:test` для формул, Playwright для пользовательских сценариев.
- У приложения нет runtime-зависимостей, backend, базы данных или обязательных переменных окружения.

## Установка и запуск

```sh
npm ci
npm run dev
```

`npm install` также поддерживается; для воспроизводимой установки используйте `npm ci` и включённый `package-lock.json`.

```sh
npm run build
npm run preview
```

Готовая статическая сборка находится в `dist/`: каталог пригоден для последующего размещения в корне сайта на Cloudflare Pages или аналогичном хостинге. Команда сборки — `npm run build`, выходной каталог — `dist`. Публикация, домен и DNS здесь не настраиваются. `preview` предназначен для локальной проверки сборки.

## Структура

```text
public/assets/images/       три исходных изображения, без перекодирования
src/components/             шапка, Hero, навигация, демонстрации, экономика,
                            консультант, подвал и модальный Workspace
src/styles/                 исходный каскад и технические исправления адаптивности
src/scripts/navigation.js   прокрутка и высота sticky-навигации
src/scripts/workflow.js     сценарии письма и процесс RFQ → сравнение
src/scripts/calculator.js   чистая функция расчёта и обновление DOM
src/scripts/consultant.js   тарифы, сценарный чат страницы, TXT-предложение
src/scripts/proposal.js     профиль Workspace, сценарный диалог, Live Proposal
src/main.js                 однократная инициализация модулей
index.html                  точка входа с компонентами
vite.config.js              включение HTML-компонентов на этапе сборки
tests/                     формулы и браузерные сценарии
docs/                      аудит и результаты проверки
```

HTML-фрагменты включаются Vite до отдачи страницы; дополнительных сетевых загрузок компонентов нет. Стили прототипа разделены с сохранением порядка переопределений, поскольку порядок важен для точного воспроизведения v4.8. Скрытый старый preview сохранён как часть эталона.

## Форматирование и тесты

```sh
npm run format
npm run format:check
npm run test
```

`npm run test` запускает реальные тесты формул и граничных значений через встроенный runner Node.js. Эталон: 100 писем, 6 минут, $15/ч, 60%, $399/мес., $900 внедрение → 132 ч, $1 980 стоимость времени, $1 581 месячный потенциал, $18 072 потенциал первого года.

Браузерные тесты требуют установки движков и системных библиотек Playwright:

```sh
npx playwright install --with-deps chromium firefox webkit
npm run test:browser
```

Playwright запускает локальный сервер автоматически. Для проверки только установленного системного Chromium в Linux:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:browser -- --project=chromium
```

Проверяются ширины 375, 390, 768, 1024 и 1440 px, прокрутка и клавиатурная навигация, калькулятор, тарифы, демонстрации, оба чата, мобильные вкладки Live Proposal и скачивание TXT. Текущие результаты и доступность браузеров — в [отчёте](docs/validation.md); установленные браузеры не следует считать одинаковыми во всех средах. HTML-отчёт и трассировки сохраняются локально в игнорируемых `playwright-report/` и `test-results/`.

## Аудит и развитие

[Карта прототипа](docs/prototype-audit.md) фиксирует исходные сценарии, формулы, ресурсы и обнаруженные технические ошибки. Исходный монолит и вложение с ТЗ не публикуются в репозитории. Изображения сохраняют исходные байты, прозрачность и C2PA-метаданные. В публичных исходниках нет ключей, закрытых endpoint и реальных клиентских данных; обязательных `.env` нет.

Будущее подключение AI следует выполнять отдельной задачей: сохранить интерфейс профиля/Live Proposal и заменить сценарную обработку через серверный адаптер, оставив секреты на сервере. В текущей версии никакого AI API-клиента или фиктивной интеграции нет. При дальнейшем рефакторинге CSS ориентироваться на контрольные скриншоты, а не менять утверждённый дизайн.
