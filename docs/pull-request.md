# Перенести утверждённый прототип v4.8 на Vite

Business Mail Automation перенесён из монолитного HTML в статический проект Vite с Vanilla JS, HTML-компонентами, отдельными стилями и исходными изображениями. Тексты, дизайн, тарифы, формулы, сценарные консультанты и Live Proposal сохранены. Исправлены скрытая экономика при обычной прокрутке, запуск существующего сценария обработки письма и клавиатурное управление Workspace.

Проверено: воспроизводимая установка, production-сборка, Prettier, 5 тестов калькулятора и 12 сценариев Chromium на пяти ширинах; npm audit — 0 уязвимостей. Контрольные скриншоты сравнены с v4.8. Firefox и WebKit пока не проверены: загрузка движков отклонена сетевой политикой среды. Подробности, визуальные различия и технические исправления — в `docs/validation.md`.

AI остаётся локальным сценарным демо; рабочие API и отправка писем отсутствуют. Публикация сайта не выполнялась. PR предназначен для проверки заказчиком, без автоматического слияния.
